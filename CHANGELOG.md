# Changelog

All notable changes to this project will be documented in this file.

## [v2.0.0] - 2026-03-24

### Added

- Revamped the main recipe experience with an updated dashboard flow.
- Introduced a redesigned landing page for signed-out users.
- Expanded recipe creation to support a more complete authoring flow.
- Added dish image upload support for recipes.

### Changed

- Migrated the app from Firebase to Supabase for authentication, database access, and storage.
- Updated the build configuration for Vercel and Vite type handling.
- Improved GitHub Actions workflow configuration.
- Refined project documentation around Supabase setup and migration.

### Fixed

- Resolved the issue that prevented newly signed-in users from adding their first dish.
